# Security policy

This app handles musicians' payment and superannuation records. Please report vulnerabilities privately through GitHub's **Report a vulnerability** button on this repository's Security tab, not in a public issue.

Include the affected route, command or SQL function, steps to reproduce against your own local copy, and the impact. Do not test against someone else's deployment or use real people's data.

In scope: authentication, session revocation, MFA gates, workspace isolation and RLS, private Storage access, calculation attestation, approval/outbox integrity and anything that could cause a duplicate or unauthorised payment instruction.
