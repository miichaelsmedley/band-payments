# Application contract v1

All commands use `POST /api/v1/commands`, JSON, a verified Supabase cookie session and an exact Origin match. Every workspace command includes `workspaceId`; this selects scope and does not confer access. Current database membership and RLS decide access. Money is integer AUD cents, dates are ISO local calendar dates. Responses are `{data: ...}` or `{error: {code,message,correlationId?}}`. Unknown fields in monetary draft schemas are rejected. Private responses are not cached.

`POST /api/v1/invoices`: authenticated multipart form with workspaceId, engagementId, invoiceNumber, amount in decimal AUD and file. Checks own engagement, 8 MB, MIME and magic bytes; uses UUID path, no original filename. Stores private object and quarantined document/invoice record. No download while pending scan. Duplicate invoice numbers within supplier/workspace are rejected. Orphan quarantine objects from a failed metadata commit need scheduled cleanup after a safe age.

`GET /api/v1/documents/:id`: session, RLS, clean scan; streams attachment after scoped Storage download. No public object URL or token in links.

`POST /api/auth`: email/password login, signout, local synthetic-account shortcuts (local environment, loopback Supabase, non-production Node only), MFA status, TOTP enrolment and challenge verification. Auth tokens are HttpOnly cookies. No public registration. Local shortcuts read ignored local credentials server-side and are disabled in production builds.

`POST /api/v1/provider/callback`: deliberately returns 503 until the approved provider's exact signature/replay contract is implemented. It does not log or consume callback data. The Edge worker similarly rejects unconfigured execution before leasing any job. Provider interface is in `src/lib/provider.ts`, bounded job algorithm in `src/lib/worker.ts`. No live adapter or endpoint is invented.

Error semantics: 401 expired/missing authentication; 403 scope/MFA/approver denial; 409 stale version or conflicting evidence; 422 financial-rule block; 400 other validation; 503 missing provider/configuration. The UI never displays raw database errors. There is no generic unauthorised service-role escape hatch.

Reads currently return a maximum of 200 rows per table. Audit explicitly labels this cap. Before a larger dataset is used, add cursor pagination and complete aggregate queries; do not infer comprehensive coverage from these lists.
